[datacom](https://github.com/moodykhalif23/datacom) running entirely in your browser: drop a messy data file, then summarize it, clean it, mask personal data, filter and total it, or convert it. The engine is the datacom command line compiled to WebAssembly, so your file is never uploaded and the results match the command line exactly.

On your own computer it is `pip install datacom`, a single binary from the [releases page](https://github.com/moodykhalif23/datacom/releases), or `datacom ui`.
