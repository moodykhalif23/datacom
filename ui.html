Summarize

Times look like 10s, 1m or 2m30s. Leave the second one blank to keep watching until you press Stop. Watch needs a typed path, because a copied file never grows. With no totals set, each window counts the new rows.

Values are copied exactly as they are. Pick the format at the bottom and press Convert.

Cleaning

With 254, “0712 345 678” becomes +254712345678. Leave it blank to keep local numbers as they are.

Numbers like “KES 1,250.00” become 1250, dates become 2025-01-15 and yes/no becomes true/false. Values that do not fit their column are kept as written and listed in the result.

Keep only rows where

Every condition must hold. Text ignores letter case; numbers and dates compare as numbers and dates.

Write a condition by hand

For example name ~ ltd (contains), email =~ @gov\.ke$ (pattern), phone not null, a > 1 and (b == x or c == y). Put a name with spaces in square brackets: [Txn Date] >= 2025-01-01.

Keep only these columns

Tick none to keep every column.

Rename columns

Current name = new name. Separate several with commas.

Calculated columns

For example amount * 0.84, if(amount > 1000, high, low), year(date), lower(status) or concat(first, ' ', last). An existing column's name replaces that column. Also available: round, abs, len, upper, trim, month, day and coalesce.
