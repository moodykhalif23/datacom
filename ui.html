3.Options

Cleaning

Numbers like “KES 1,250.00” become 1250, dates become 2025-01-15, yes/no become true/false, spacing is tidied. Values that do not fit their column are kept as written and reported.

Keep only rows where…

Every condition must hold. Text comparisons ignore letter case; numbers and dates compare as numbers and dates.

Write a condition by hand

Examples: name ~ ltd (contains), email =~ @gov\.ke$ (pattern), phone not null, a > 1 and (b == x or c == y). Put a column name in square brackets if it has spaces: [Txn Date] >= 2025-01-01.

Keep only these columns

Leave all unticked to keep every column.

Rename columns

old name = new name, separated by commas.

Add calculated columns

Examples: amount * 0.84, if(amount > 1000, high, low), year(date), lower(status), concat(first, ' ', last). Using an existing column's name replaces it. Available: round, abs, len, lower, upper, trim, concat, year, month, day, if, coalesce.

Totals by group

One row comes out per group, with the totals you ask for. With nothing ticked, one row for the whole file.

Order and size

Empty values always go last.
