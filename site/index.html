Clean, profile and query data files too big or too messy for a spreadsheet.

datacom turns exports full of stray spaces, mixed date formats, numbers like “KES 1,250.00”, duplicate rows and garbled text into clean, typed data, and tells you about every change it made. Values that do not fit are kept as written and listed, never guessed at.

It is one small program with nothing else to install, and it runs on your own computer. Files larger than memory stream straight through: on an eight-thread machine it cleans ten million messy rows from a gzipped file in about ten seconds, using 35 MB. The terminal, Python and the browser all drive the same engine, so results match exactly.

datacom ui opens the same tools in your browser, for colleagues who do not use a terminal.

datacom has what you would expect from a data cleaner:

  • Reads CSV with any delimiter, TSV, JSON, NDJSON, Excel, OpenDocument, Parquet, Avro and XML, plain or in gzip, zstd or zip, and writes all of them, plus HTML tables and SQL
  • Fixes numbers, dates, yes/no values, phone numbers and column names, and drops empty and duplicate rows
  • Summarizes any file: types, missing values, common values and the problems worth fixing
  • Filters, calculated columns, joins, totals by group and sorting, from one small expression language
  • Follows a file that is still being written and reports on each new window of rows
  • Retries and resumes downloads over slow or unreliable networks

And what AI training data and audited work need:

  • Masks emails, phone numbers, ID numbers and card numbers, with a count for each
  • Cleans document text: garbled characters, HTML, mixed Unicode forms and control characters
  • Drops low-quality documents, near-duplicates within a fixed memory budget, and anything that overlaps a test set, each rule counted on its own
  • Writes a record of every run with the SHA-256 of each input and output and what each rule changed
  • Reads many files at once from folders, S3, Google Cloud Storage or the Hugging Face Hub and writes the result in parts on every core

Install

Download the binary for Windows, macOS or Linux from the releases page, or use one of these:

pip install datacom
go install github.com/moodykhalif23/datacom@latest

First steps

# what is in this file?
datacom profile sales.xlsx

# fix values, drop duplicates, mask personal data
datacom clean raw.csv.gz -snake -dedupe -redact all -o clean.parquet

# totals by region
datacom query sales.csv -where "amount > 1000" -group region -agg "count,sum(amount)"

# the same, point and click
datacom ui

From Python, datacom.clean("raw.csv", "clean.parquet", dedupe=True) returns the run record as a dict. The documentation covers every option.
