Upload a messy data file and summarize or clean it with [datacom](https://github.com/moodykhalif23/datacom): numbers, dates, yes/no values and phone numbers fixed, duplicates dropped, personal data masked, and document text prepared for AI training. Each clean returns its run record with checksums and what every rule changed.

The same engine runs on your own computer with `pip install datacom`, as a single binary from the [releases page](https://github.com/moodykhalif23/datacom/releases), or as `datacom ui` in your browser.
